# Initial Concept
Hei-San-Ban (平三盤): A digital balanced ternary abacus designed for educational exploration and practical computation in base-3 symmetric logic.

# Product Guide

## Vision
Hei-San-Ban aims to demystify the balanced ternary number system by providing a tactile, interactive interface inspired by the Japanese Soroban. It bridges the gap between abstract mathematical concepts and physical representation, allowing users to perform additions and subtractions using digits {-1, 0, +1}.

## Target Users
- **Students and Educators:** Those learning or teaching computer science, number systems, or the history of computing (e.g., the Setun computer).
- **Mathematics Enthusiasts:** People interested in non-standard positional systems and symmetric logic.
- **Curious Learners:** Users looking for a unique take on the traditional abacus.

## Core Features
- **Interactive Abacus Interface:** Responsive rods and beads where the top bead represents +1 and the bottom bead represents -1 when touching the center bar.
- **Real-time Conversion:** Automatic calculation of the total value in decimal (Base 10).
- **Mathematical Notation:** Live rendering of the balanced ternary expansion using LaTeX (MathJax).
- **Bilingual Support:** Full content toggle between English and Portuguese.
- **Educational Content:** Integrated tutorials on how to use the abacus, including specific guides for addition and subtraction logic.
- **PWA (Progressive Web App):** Offline support and installability for mobile and desktop use.

## Success Criteria
- Users can successfully represent any integer within the rod limit.
- The interface remains intuitive and responsive across different device sizes.
- Educational sections clearly explain the carry/borrow logic unique to balanced ternary.
